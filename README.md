# backend-mongoDB
# Backend MongoDB & Mongoose Projects

This repository contains my backend development coursework and assignments focused on building backend applications using Node.js, MongoDB, and Mongoose.

The projects in this repository demonstrate database connectivity, Mongoose schemas, data validation, CRUD-related operations, and storing different types of structured data in MongoDB.

---

## Repository Overview

The repository contains multiple backend coursework and homework projects from different lessons.

Each project is maintained in a separate folder so that the implementation and learning from each assignment can be easily understood.

---

## Tech Stack

The following technologies and tools are used throughout the repository:

- **Node.js** - Backend JavaScript runtime
- **MongoDB** - NoSQL database
- **MongoDB Atlas** - Cloud database platform
- **Mongoose** - MongoDB object modeling library
- **JavaScript** - Programming language
- **dotenv** - Environment variable management
- **File System (fs)** - Reading JSON files
- **Git** - Version control
- **GitHub** - Source code hosting
